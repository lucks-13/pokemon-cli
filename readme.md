This project currently include pokemon data, moves, trainers, a map, a main menu, battle interface, save and load functionality.

# What my project does.

This python cli game lets you to :
* Move around small map
* Interact with object on map
* View Pokemon and Pokedex Message
* Create and Save a Trainer
and much more.

# How to run this project.

Clone the repository:

```
git clone https://github.com/lucks-13/pokemon-cli.git
```
Run the project with.
```
python -m src.main
```

# Controls

### W - Move Forward 
### A - Move Backward 
### S - Move Left
### D - Move Right
### E - Interact
### M - Open the Menu

rest all explore and find it out yourself.
